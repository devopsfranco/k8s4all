# Module 06: Managing Change

## Overview

Change is constant, but it doesn't have to be chaotic. This module helps you understand change dynamics and lead (or navigate) transitions effectively.

## Core Concept

**Forcing change**: Push harder when resistance appears
**Managing change**: Understand dynamics, work with human reality

## Learning Objectives

1. Understand why people resist change
2. Prepare for change before announcing it
3. Communicate change effectively
4. Navigate resistance productively
5. Maintain momentum through transitions
6. Make change stick

## Time Commitment

**60-90 minutes**
