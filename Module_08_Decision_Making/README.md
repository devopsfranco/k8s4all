# Module 08: Decision Making Under Uncertainty

## Overview

Every day you make decisions with incomplete information. This module helps you decide thoughtfully despite uncertainty.

## Learning Objectives

1. Make sound decisions with incomplete information
2. Use decision frameworks appropriately
3. Think through trade-offs systematically
4. Handle different types of uncertainty
5. Avoid common decision traps
6. Learn from decisions to improve over time

## Time Commitment

**60-90 minutes**
